# 注册账号

本文档介绍如何注册 LightMind 账号。

## 操作步骤

1. 打开 [LightMind 网页版](https://www.lightmind.top/)，在登录页面点击 **还没有账号？注册**。

   ![注册页面](/截屏2026-07-31%2017.41.10.png)

2. 输入手机号和密码，点击 **下一步**。

   ![输入手机号和密码](/截屏2026-07-31%2017.43.40.png)

3. 根据页面提示完成人机验证。

   ![人机验证](/截屏2026-07-31%2017.45.51.png)

4. 输入收到的短信验证码，完成验证。

   ![短信验证码](/截屏2026-07-31%2017.47.55.png)

5. 注册成功后，系统将自动进入 LightMind。

   ![注册成功](/截屏2026-07-31%2017.54.43.png)

🎉 **注册完成！**
